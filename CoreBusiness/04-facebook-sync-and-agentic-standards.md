# 04 — ระบบซิงก์โพสต์ Facebook อัตโนมัติ และรากฐานมาตรฐาน AI Agent สากล

## 1. ระบบดึงโพสต์จาก Facebook Page อัตโนมัติ (Phase 1 Priority #1)

กลุ่มเป้าหมายหลักของที่พักในประเทศไทยเกือบ 100% ใช้ **Facebook Page** เป็นช่องทางสื่อสารรายวัน ดังนั้นระบบซิงก์คอนเทนต์เฟสแรกจะเน้น **Facebook Page (Meta Pages Graph API)** เป็นอันดับที่ 1 (และขยายสู่ Instagram / TikTok ในเฟสถัดไปบนโครงสร้างตารางเดียวกัน)

### 1.1 ปัญหาจริงของ Facebook Page ที่พักไทย และวิธีแก้ด้วย "AI 3-Tier Smart Triage"
เพจ Facebook ของรีสอร์ทไทยมักไม่ได้ลงแค่รูปห้องพักสวยๆ แต่มีโพสต์ปะปนหลากหลาย เช่น:
- โพสต์มุกตลก คำคม มีมไวรัล หรือแชร์ข่าวประจำวัน
- โพสต์แจ้งเตือนชั่วคราว เช่น *"วันนี้ฝนตกหนัก ปิดสระว่ายน้ำซ่อมบำรุง 1 วัน"* (ซึ่งอาจแนบรูปสระว่ายน้ำมาด้วย!)
- รูปป้ายประกาศกราฟิกตัวหนังสือแน่นเต็มภาพ (เช่น ป้ายโปรไฟไหม้เฉพาะคืนนี้)

หากปล่อยดึงขึ้นหน้าแรกแบบ Auto 100% โดยไม่คัดกรอง จะทำให้เกิดรูปขยะหรือข้อมูลราคาผิดพลาดบน Masonry Feed ทันที ดังนั้น Cangaroom จึงออกแบบกระบวนการคัดกรองอัจฉริยะ **3 ระดับ (3-Tier Smart Triage)** ดังนี้:

| ระดับการคัดกรองโดย Vision + Text AI | ลักษณะของโพสต์ที่ตรวจพบ | การจัดการของระบบ (ค่าเริ่มต้น: ปลอดภัยและไม่เหนื่อย) |
| :--- | :--- | :--- |
| **Tier 3 — ขยะ / ไม่เกี่ยวกับห้องพัก (`Score < 40`)** | มีมตลก, แชร์ข่าว, รูปคำคมสวัสดีวันจันทร์, โพสต์แจ้งเหตุขัดข้อง/ปิดปรับปรุง, โพสต์ตัวหนังสือล้วนไม่มีภาพที่พัก | **ตัดทิ้งอัตโนมัติ (`DISCARDED`)** ไม่นำขึ้นหน้าเว็บและไม่แจ้งเตือนให้รกหน้าหลังบ้านของเจ้าของที่พัก |
| **Tier 2 — โพสต์ป้ายโปรโมชั่น / ส่วนลด (`Promo Graphic`)** | ภาพกราฟิกที่มีตัวหนังสือเยอะแจ้งลดราคาหรือแจกโค้ดส่วนลด | **ไม่นำรูปกราฟิกรกตาขึ้น Masonry Feed** แต่สกัดข้อความส่วนลดมาสร้างเป็น **ร่างคูปอง (Draft Coupon)** รอให้เจ้าของที่พักกดเปิดใช้งานใน `/studio` เพื่อส่งเข้าหน้า `/deal` |
| **Tier 1 — ภาพถ่าย/วิดีโอที่พักสวยคมชัด (`Score >= 85`)** | ภาพถ่ายบรรยากาศจริง ห้องพัก วิวภูเขา/ทะเล สระว่ายน้ำ อาหารเช้า หรือคลิปพาทัวร์ห้อง | AI ตั้งชื่อ เตรียมคำบรรยาย ติดแท็กจังหวัด/สไตล์ และจับคู่กับ `Room` ที่ตรงกันไว้ล่วงหน้าในถัง **`รออนุมัติ (PENDING_APPROVAL)`** ให้เจ้าของที่พักกดปุ่ม **`อนุมัติขึ้นเว็บใน 1 คลิก`** (และสำหรับเพจที่คุมโทนรูปสวยอยู่แล้ว เจ้าของสามารถเลือกเปิดสวิตช์ `Auto-Publish เฉพาะ Tier 1` ได้เองในภายหลัง) |

### 1.2 ความเป็นอิสระของโพสต์ที่ดึงมา (100% Native Cangaroom Pin & Media Ownership)
- **คัดลอกไฟล์ภาพ/วิดีโอขึ้น CDN ของ Cangaroom เอง (Cloudinary)**: ห้ามผูกติดกับลิงก์รูปชั่วคราวของ Facebook (`fbcdn.net`) เพราะลิงก์ต้นทางจะหมดอายุภายในไม่กี่วัน ระบบต้องอัปโหลดเก็บเป็นไฟล์ของ Cangaroom เองทันทีที่นำเข้า
- **แยกขาดจาก Like / Comment ของต้นทาง 100%**: โพสต์ที่นำเข้ามาจะเกิดใหม่เป็น **Native Pin ของ Cangaroom** อย่างสมบูรณ์ ยอด Like, Comment (รวมถึงการตอบกลับของเจ้าของที่พัก), การกดบันทึกเข้า `/board`, และการกด Share จะทำงานอยู่บนฐานข้อมูลของ Cangaroom เองทั้งหมด ไม่ปะปนกับคอมเมนต์สแปมบน Facebook ต้นทาง

### 1.3 แนวทางการสื่อสารระหว่าง Traveller กับ Hotel บน WebApp (ทำไมไม่ควรสร้างแชทสดเองในเฟสแรก)
- เนื่องจาก Cangaroom เป็น **WebApp (ไม่มี Native Mobile App)** การสร้างระบบแชทสดเก็บข้อความบนเว็บจะมีจุดอ่อนร้ายแรงคือ **ไม่มี Push Notification เด้งปลุกบนมือถือ iOS/Android เมื่อปิดเบราว์เซอร์** ทำให้เจ้าของที่พักตอบช้าและลูกค้าไม่เห็นข้อความตอบกลับ ส่งผลให้เสียยอดจอง
- กอปรกับโมเดล **0% GP** ของเรา **ไม่ต้องกลัวลูกค้าออกไปคุย LINE กับโรงแรม** (ต่างจาก Agoda/Airbnb ที่ต้องบล็อกช่องทางติดต่อเพราะกลัวเสียค่าคอมมิชชัน)
- **สถาปัตยกรรมที่แนะนำ**:
  1. **Phase 1–2 (`Smart Direct Contact Handoff + Public Pin Q&A`)**: ใช้ปุ่มติดต่อที่พักตรงผ่าน **LINE OA / Facebook Messenger / โทรศัพท์** บนหน้า `/{hotelSlug}` ที่แนบข้อความบริบทห้องและวันที่สนใจไปให้อัตโนมัติ พร้อมบันทึกสถิติการคลิก (`ContactClickLog`) เพื่อให้เจ้าของโรงแรมเห็นใน `/studio` ว่า Cangaroom ส่งลูกค้าทักแชทไปกี่คน ร่วมกับระบบ **ถาม-ตอบสาธารณะในช่อง Comment ใต้ Pin**
  2. **Phase 3+ (`Hotel AI Agent + LINE OA Webhook Bridge`)**: เมื่อเปิดแชทบนหน้าเว็บ ให้ใช้ AI ประจำโรงแรมตอบคำถามข้อมูลห้องว่างทันทีใน 2 วินาที และหากต้องส่งต่อคนจริง ให้เชื่อม LINE Messaging API ยิงเข้า LINE ของเจ้าของโรงแรมโดยตรงโดยไม่ต้องเปิดเว็บค้างไว้

## 2. การปูรากฐานมาตรฐานสากลสำหรับยุค AI Agent (Agentic Web Ready — Phase 1)

ในอนาคตอันใกล้ นักเดินทางจะสั่งงานผ่าน **Personal AI Agent** (เช่น ChatGPT, Gemini, Claude, Apple Intelligence) ให้คุยประสานงานกับแพลตฟอร์มที่พักโดยตรง แทนการเปิดเว็บไล่คลิกเองทีละหน้า

เพื่อให้ Cangaroom ก้าวทันมาตรฐานเดียวกับ **Shopify, Expedia และ Booking.com** โดยไม่ซับซ้อนเกินความจำเป็นในเฟสเปิดตัว เราจะปูรากฐานมาตรฐานสากลไว้ 4 จุดตั้งแต่วันแรก:

### 2.1 สถาปัตยกรรม Headless Service Layer (ใช้ฟังก์ชันแกนกลางชุดเดียวกัน)
แยก Service ฝั่ง Server ออกมาไว้ที่ `src/lib/services/*` อย่างชัดเจน เช่น:
- `staySearchService.searchAvailableStays(...)` — ค้นหาที่พักตามจังหวัด สไตล์ งบประมาณ เงื่อนไขสัตว์เลี้ยง และเช็กห้องว่างจริงตามวันเข้าพัก-ออก
- `hotelProfileService.getHotelStorefront(slug)` — ดึงรายละเอียดโรงแรม ห้องพัก รีวิว แผนที่ และคูปองที่ใช้งานได้
- `couponService.findBestApplicableCoupons(...)` — คำนวณคูปองส่วนลดที่คุ้มที่สุดสำหรับห้องและวันเข้าพักนั้น
- `bookingService.createBookingHold(...)` — ล็อกห้องพักชั่วคราว 15 นาทีและสร้างรายการชำระเงินตรง

ทั้ง **หน้าเว็บ React ของมนุษย์** และ **Endpoint สำหรับ AI Agent** จะเรียกใช้ฟังก์ชันชุดเดียวกันนี้ 100% ทำให้ไม่ต้องดูแลโค้ดซ้ำซ้อนสองชุด

### 2.2 มาตรฐานนามบัตร Agent2Agent (`/.well-known/agent-card.json` & `llms.txt`)
- เปิด Route มาตรฐานสากล **`GET /.well-known/agent-card.json`** (ตามโปรโตคอล A2A) และ **`GET /llms.txt`** เพื่อประกาศให้ AI Agent ทั่วโลกรู้จักความสามารถของ Cangaroom ในฐานะแหล่งรวมที่พักจองตรง 0% GP ในประเทศไทย พร้อมอธิบายพารามิเตอร์การค้นหาและการสร้างลิงก์จองตรง
- ในทุกหน้าโปรไฟล์ที่พัก `cangaroom.com/{hotelSlug}` จะฝัง **JSON-LD (`Schema.org/LodgingBusiness`, `HotelRoom`, `Offer`)** ที่ดึงราคาและสถานะจริงจากฐานข้อมูลโดยอัตโนมัติ

### 2.3 มาตรฐาน Model Context Protocol (`POST /api/mcp`)
เปิด Public Read & Booking-Intent MCP Endpoint เบื้องต้นที่มี Tools มาตรฐาน 4 คำสั่ง:
1. `search_thailand_stays` — รับค่าจังหวัด, วันเช็กอิน-เอาต์, จำนวนผู้เข้าพัก, งบประมาณต่อคืน, สไตล์ที่พัก และคำค้นเชิงความหมาย คืนค่ารายชื่อที่พักที่ว่างจริงพร้อมราคาสุทธิ (โดยให้สิทธิ์จัดอันดับร่วมกับระบบ `SponsoredCampaign` ที่ตรงเงื่อนไขลูกค้าจริง)
2. `get_hotel_details` — ดึงรายละเอียดเชิงลึกของ `/{hotelSlug}` ทั้งห้องพัก กฎระเบียบ นโยบายสัตว์เลี้ยง และรูปภาพจริง
3. `list_active_coupons` — ดึงคูปองที่กดใช้ได้ทันทีของโรงแรมหรือจังหวัดนั้นๆ
4. `create_direct_booking_link` — คำนวณยอดสุทธิหลังหักคูปองและคืนค่า **Direct Checkout Deep Link** (`https://cangaroom.com/{hotelSlug}?room=...&checkIn=...&checkOut=...&coupon=...`) เพื่อให้มนุษย์เจ้าของเครื่องเป็นคนกดโอนเงินยืนยันขั้นสุดท้ายอย่างปลอดภัยสูงสุด (Human-in-the-Loop Payment Confirmation)
