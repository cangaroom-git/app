## Non-Negotiable Design Constitution v3.0 — Airbnb Warm Minimal (Read Every Turn)

1. **ZERO HOVER SCALE (`ห้ามใช้ hover แล้ว scale ทั้งเว็บเด็ดขาด`)**:
   - **NEVER** use `hover:scale-*`, `group-hover:scale-*`, or `:hover { transform: scale(...) }` on ANY image, card, button, or icon anywhere in the codebase.
2. **MINIMAL BORDERS & EQUAL SECTION RHYTHM (`ลดเส้นขอบ 4 ด้าน และแบ่ง Section ให้เท่ากัน`)**:
   - **ZERO BORDER FATIGUE**: NEVER wrap inline room cards, side-menu nav items, add-ons, POI sidebar rows, review items, guide cards, or secondary pills in 4-sided `border` boxes.
   - Separate consecutive sections & list rows strictly with single `1px` horizontal hairlines (`divide-y divide-[var(--color-border)]` or `border-t border-[var(--color-border)]`) and uniform vertical spacing (`py-8 lg:py-10` on `/{hotelSlug}`, `py-8 first:pt-0` on `/{hotelSlug}/book`, `py-4`–`py-5` on list rows).
   - **UNIFIED AIRBNB INSET-LABEL INPUT STANDARD (บังคับใช้เหมือนกันทุก Input / Text Field ทั้งเว็บ)**:
     - EVERY `<input>`, `<textarea>`, and form select field MUST follow the **Airbnb Inset-Label White Field** style (matching `HotelStorefrontClient.tsx` sticky widget & Airbnb Property Type form): pure white `bg-[var(--color-background-card)]`, `rounded-[12px]`, calm `1px border-[#b0b0b0]` (`dark:border-[var(--color-border-emphasized)]`), `min-h-[56px] px-3.5 py-2`, small inset label (`12px text-[var(--color-text-secondary)]`) INSIDE top-left with value (`15px text-[var(--color-text-primary)]`) directly below, and crisp `focus-within:border-[var(--color-text-primary)] focus-within:ring-1 focus-within:ring-[var(--color-text-primary)]`.
     - Related inputs pair inside `<StandardFieldGroup />` (`divide-y` / `divide-x` with `#b0b0b0` hairlines); integer counts (bedrooms, beds, bathrooms, guests, units) use `<StandardStepperRow />` (`−` / count / `+`) instead of raw number inputs; checkboxes MUST use `<StandardCheckbox />` (NEVER raw `<input type="checkbox">`). Always use `<StandardInput />`, `<StandardTextarea />`, `<StandardCheckbox />`, `<StandardFieldGroup />`, `<StandardStepperRow />` from `src/components/ui/standards.tsx`, and `<StudioDateRangePicker />` (Airbnb 2-month popover / mobile bottom sheet) instead of native `<input type="date">`.
3. **ZERO CARD/BUTTON SHADOWS & ZERO GRADIENTS/PASTELS**:
   - **NEVER** apply `shadow-sm/md/lg/xl` to inline content cards, banners, or buttons (`--shadow-card: none`).
   - **Strictly 2 Shadow Exceptions**: `--shadow-booking-widget` (`0 6px 16px rgba(0, 0, 0, 0.12)`) ONLY on the desktop sticky booking/checkout summary card; `--shadow-popover` (`0 6px 20px rgba(0, 0, 0, 0.14)`) ONLY on floating dropdowns, modals/bottom sheets, floating map cards/controls, and mobile floating nav.
   - **NEVER** use `bg-gradient-*`, `#0866ff` blue, `#06c755` green, or pastel tinted boxes.
4. **WANDERLUST TRAVEL-BLUE PALETTE, 2-BUTTON HIERARCHY & FULL-ROUND PILL BUTTONS**:
   - Canvas `#ffffff` (`#11161d` Dark), Sky Cloud Muted `#f3f7fc` (`#18202b` Dark), Hairline `#e3ebf4` (`#283444` Dark), Primary Ink `#182334` (`#f1f5fa` Dark), Secondary Ink `#5c6b80` (`#9ba8bc` Dark), Travel-Blue Accent `#1e78d6` (`#4ca3f5` Dark), Typography `Plus Jakarta Sans` + `Anuphan`.
   - **Primary Button**: Solid Travel-Blue `var(--color-accent)` (`#1e78d6` Light / `#4ca3f5` Dark) + `var(--color-on-accent)` for primary actions (`จองห้องพัก`, `ยืนยัน`, `ค้นหา`, `เช็กวันว่าง`).
   - **Secondary Button**: Flat borderless `var(--color-background-muted)`, `hover:bg-[var(--color-background-subtle)]`.
   - **Full-Round Pill Buttons & Square Media Standard**: Every interactive `<button>`, filter pill, and icon button MUST use **`rounded-full`** (never squircle boxes for primary/secondary buttons or filter pills). Multi-line `<input>` / `<textarea>` fields keep clean inset-label `rounded-[14px]`–`rounded-[16px]`. All place cards, feed photos, room cards/modals, and review thumbnails MUST use **`aspect-square`** (`rounded-[18px]`–`rounded-[24px]`); only the Desktop `/{hotelSlug}` 5-Photo Hero Mosaic (`aspect-[2/1]`), full-screen maps, and video players keep non-square viewports.
   - **5% Reserved Red (`#e60023`) & Scoped 5-Category Card Crest Exception**:
     - `#e60023` Red is allowed **ONLY** on the Heart Wishlist `'บันทึก'` button, liked heart state, and tiny nav notification dots (NEVER use `Bookmark` icons for saving).
     - **5-Category Soothing Matte Crest Colors** (`STAY #5369A6`, `CAFE #D47E35`, `RESTAURANT #C6566E`, `ATTRACTION #529D48`, `WELLNESS #3A8D9A`) are explicitly allowed **STRICTLY** on the Category Medallion of `1:1` Collectible Place Cards and Map Pins (`/explore`, `/trip`) — NEVER on action buttons, gradients, or pastel card washes.
     - **Modern Super-Rounded `1:1` Collectible Place Card**: ZERO card border/rim, rounded `aspect-square` (`rounded-[22px] sm:rounded-[24px]`), Top-Left Category Medallion, Top-Right Heart Wishlist button, ZERO "Video" tag (autoplay muted looping `<video>` when video exists), ZERO store name on photo (clean 2–3 lines + rating stars below photo). Stacked cards (`/trip`) stand straight upright (`rotate(0deg)`) stepping horizontally right with progressively smaller & faded back cards.
5. **MOBILE/TABLET INTERACTION, CUSTOM SELECT & MAP STANDARDS**:
   - **NO NATIVE `<select>`**: Always use `<ResponsiveSelect />` (popover on Desktop / slide-up Bottom Sheet on Mobile).
   - **Slide-Up Bottom Sheet Standard for ALL Mobile Modals**: EVERY modal, dialog, picker, action menu (`More ...`), auth prompt, and save-action bar on Mobile (`< sm` / `< lg`) MUST slide up from the bottom edge of the viewport (`items-end`, `w-full`, `rounded-t-[24px]`, top drag handle `h-1 w-10 rounded-full`, `animate-slide-up-sheet`, safe-area bottom padding) — NEVER centered floating popups or small bottom-left desktop cards on mobile. Any sheet inside a transformed (`will-change-transform`) or `overflow-hidden` ancestor MUST use `createPortal(..., document.body)` (`z-[95]`) with `stopPropagation`.
   - **Bottom Sheets + Snap Carousels**: Clamp mobile text/lists + open `<HotelInfoBottomSheet />`; pair `-mx-4 px-4` with `scroll-px-4` on horizontal snap carousels; keep anchor bars vertically locked (`overflow-y-hidden touch-pan-x`).
   - **Seamless WebGL Vector Map (`/map` & `HostLocationPicker`)**: Use MapLibre GL (`setWorkerUrl("/maplibre-gl-worker.js")`) + OpenFreeMap vector style (`airbnbMapLibreStyle.ts` warm minimal palette, zero raster tile grid) + full-bleed `/map` modal with Airbnb floating top-left search/category/results popover (no wall-to-wall sidebar) + `HostLocationPicker` in `/studio` & `/register-hotel` (auto-extracts Google Maps links + drag-to-pin + province guardrail, zero manual lat/lng typing).
6. **SMOOTH AIRBNB / iOS MOTION & FADE SLIDE-IN / SLIDE-OUT CONSTITUTION (`กฎมาตรฐาน Animation ลื่นไหลทั้งเว็บ`)**:
   - **Smooth Fade Slide-In + Slide-Out (`useModalPresence`)**: Every modal, bottom sheet, drawer, floating card, pill, and popover MUST animate **both Fade Slide-In AND Fade Slide-Out** (`translate3d + opacity`) via `useModalPresence` (`src/lib/useModalPresence.ts`) + GPU-composited `data-state="open" | "closed"` classes (`.cgr-modal-backdrop`, `.cgr-modal-fade-slide`, `.cgr-modal-surface-*`, `.cgr-floating-card-motion`, `.cgr-popover-motion`, `.cgr-fade-slide-pill`) using `--ease-out-expo` (`cubic-bezier(0.22, 1, 0.36, 1)`) and `--ease-ios-sheet` (`cubic-bezier(0.32, 0.72, 0, 1)`), with exit ~25–30% faster than enter (`360ms` in / `250ms` out) and `useBodyScrollLock(shouldRender)`.
   - **Continuous Sheet Morphing & Live Finger-Drag (`ห้ามสลับกล่องตัดฉับ`)**: Multi-state mobile sheets (e.g., `/explore` 90% Map / 10% Peek <-> Half <-> 100% Full List, or Nearby Map Idle <-> Search <-> Results) MUST morph **ONE persistent sheet container** smoothly (`.cgr-map-mobile-sheet`, `420ms var(--ease-ios-sheet)`) with 1:1 live `touchmove` finger tracking (`data-dragging="true"`) rather than unmounting/remounting separate divs.
   - **GPU-First, Zero Hover-Scale & Reduced Motion**: Animate `translate3d` + `opacity` (never `hover:scale-*`), cache last item during detail-card fade slide-out so content doesn't flash empty, and always respect `@media (prefers-reduced-motion: reduce)`.
7. **UNIFIED SHELL & 3-TIER CONTAINER GRID**:
   - Persistent `72px` Left Sidebar + `64px` Top Bar on Desktop (`>= lg`); zero top navbar on Mobile/Tablet (`< lg`, replaced by clean docked 5-icon Airbnb Bottom Bar: `Coupon`, `Explore`, `Search`, `Trip`, `Log in / Profile`, auto-hidden on `/{hotelSlug}` in favor of the sticky booking footer).
   - Strictly 3 widths: `cgr-page-fluid` (`/` & `/trip` map stage), `cgr-page-standard` (`max-w-[1120px]`: `/deal`, `/{hotelSlug}`, `/{hotelSlug}/book`, `/{hotelSlug}/posts`, `/bookings`, `/studio`, `/super-admin`), and `cgr-page-reading` (`760px`) / `cgr-page-form` (`640px`).
